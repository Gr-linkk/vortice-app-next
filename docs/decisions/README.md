# Decision Records

Use a decision record when a choice changes architecture, product semantics,
security boundaries, data ownership, service targets, or the way future work is
performed.

Copy `0000-template.md`, assign the next number, and keep the record short.
Statuses are `Proposed`, `Accepted`, `Superseded`, or `Rejected`. Do not edit an
accepted decision to reverse it; add a new record and link both records.
